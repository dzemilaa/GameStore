# 🎮 GameStore

> A modern full-stack web application for browsing and managing games, built with ASP.NET Core API and a dynamic React frontend.

---

## 🛠️ Tech Stack

### Frontend
* **React** / JavaScript
* **CSS / Styling**

### Backend & Database
* **ASP.NET Core 10** (.NET, C#) – located in `GameStore.Api`
* **Entity Framework Core** (ORM)

---

## ⚙️ Project Structure
* `GameStore.Api/` - ASP.NET Core Web API backend
* `GameStore.React/` - React frontend client

---
